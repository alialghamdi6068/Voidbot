# Voidbot 🔥

بوت Discord مع لوحة تحكم Web باللغة العربية، مبني باستخدام Python وdiscord.py وFlask.

## ✨ الأنظمة

- 🛡️ إدارة السيرفر: حظر، طرد، تايم، تحذيرات، مسح، قفل وفتح الرومات.
- 🎫 التذاكر: لوحة فتح التذاكر، استلام، إغلاق، إضافة وإزالة أعضاء.
- 📝 التقديمات: نموذج تقديم مع قبول ورفض وإشعار للمتقدم.
- 📈 المستويات: XP، مستويات، ترتيب أفضل الأعضاء وإعلانات رفع المستوى.
- 👋 الترحيب والرتبة التلقائية.
- 📋 اللوق والنشاط.
- 🎉 القيفاواي مع مدة وفائزين وإعادة اختيار.
- 💡 الاقتراحات.
- 💤 AFK.
- 💬 الردود التلقائية.
- 📢 الإعلانات.
- ⏰ التذكيرات والجدولة.
- 📨 أدوات المراسلة.
- 🌐 لوحة تحكم لإعداد أنظمة السيرفر.

## ⚙️ المتطلبات

- Python 3.11 أو أحدث.
- Discord Bot Token.
- Discord OAuth2 Application للـDashboard.
- الصلاحيات المطلوبة للبوت حسب الأنظمة المستخدمة.

## 🔐 متغيرات البيئة

ضع القيم التالية في بيئة الاستضافة:

```env
DISCORD_TOKEN=ضع_توكن_البوت
DISCORD_CLIENT_ID=معرف_تطبيق_ديسكورد
DISCORD_CLIENT_SECRET=سر_تطبيق_ديسكورد
DISCORD_REDIRECT_URI=https://YOUR-DOMAIN/callback
SESSION_SECRET=ضع_قيمة_عشوائية_قوية
PORT=10000
HOST=0.0.0.0
```

> لا ترفع `.env` أو توكن البوت إلى GitHub.

## ▶️ التشغيل محليًا

```bash
pip install -r requirements.txt
python bot.py
```

## 🌐 لوحة التحكم

بعد تشغيل البوت، افتح:

```text
http://localhost:10000
```

وسجّل الدخول بواسطة Discord OAuth2.

## 🤖 الأوامر

البوت يستخدم البادئة `!` للأوامر النصية، بالإضافة إلى أوامر Slash في الأنظمة التي تدعمها.

أمثلة:

```text
!تكت
!تقديم
!قيفاواي 10m 1 الجائزة
!لفل
!توب
!باند @member
!طرد @member
!تايم @member 10
```

## 🗄️ قاعدة البيانات

يستخدم المشروع SQLite لتخزين إعدادات السيرفرات، التحذيرات، المستويات، التذاكر، التقديمات، الاقتراحات، القيفاواي، التذكيرات والجدولة.

يمكن تحديد مسار قاعدة البيانات عبر `DATABASE_PATH`، ومجلد البيانات عبر `DATA_DIR`.

## 🚀 الاستضافة

يمكن تشغيل المشروع على أي استضافة تدعم Python وتشغيل Web Server، مع ضبط متغيرات البيئة والمنفذ `PORT` حسب الاستضافة.

## 🧰 التطوير

عند إضافة نظام جديد:

1. أنشئ Cog داخل `cogs/`.
2. أضف اسمه إلى قائمة التحميل في `bot.py`.
3. أضف إعداداته إلى `web/api.py` وواجهة النظام إذا احتاج Dashboard.
4. حدّث قاعدة البيانات في `database.py` عند الحاجة.
5. اختبر تشغيل البوت قبل الدمج إلى `main`.
